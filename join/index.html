Join a group in Facit

You scanned the invite code for a group in Facit, the flashcard app. Join it in the app:

  1. Get Facit, or open it if you have it.
  2. Tap Scan QR code on its main screen.
  3. Point it at the invite code on the admin's phone, and tap Ask to join.

Download Facit on the App Store

With Facit installed, the iPhone Camera opens the invite code in Facit directly.
